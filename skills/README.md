# skills/ —— 可复用开发任务模板

> 本目录收录「会反复做」的扩展任务的步骤化指南,让任何 AI 协作工具(Claude Code / Cursor / Codex …)或新同学不通读全库就能照着加。
> ⚠️ 文中提到的 `specs/`、`CLAUDE.md`、`OVERVIEW.md` 等内部规划文档**不在本仓库中**,这些引用无法解析;可执行的参考是各指南里指向 `src/` 的符号名。

每份指南遵循同一骨架:**何时用 → 前置阅读 → 你要满足的契约 → 编号步骤(附 file:line + 抄哪个现成例子)→ 常见坑 → 提交自检**。

| Skill | 何时用 | 状态 |
|---|---|---|
| [新增一个工具](add-tool.md) | 给 Agent 加一个内置工具(LLM 可调用的 function) | ✅ 已完成 |
| 新增一个 Adapter | 接入一个新的 agent 平台(如 Codex / OpenCode) | ✍️ 尚未编写 |
| 新增一种 MessagePart 类型 | 消息里要渲染一种新内容块(且 markdown 表达不了) | ✍️ 尚未编写 |
| 新增一种 Artifact 类型 | 产物面板要支持一种新产物(如激活 diff、新增图表) | ✍️ 尚未编写 |

> ⚠️ **行号会随代码漂移**。各指南里的 `file:line` 是写作时的快照(原始基线 commit 已不可考);若对不上,**以文中的符号名 / 函数名为准**搜索定位。
